# Запуск TnDtun для Windows

Распакуйте ZIP целиком, запустите **TnDtun.exe** и подтвердите запрос Windows на права администратора. Активируйте код в «Подписках» или импортируйте собственный профиль в настройках. Выберите профиль и нажмите «Подключить».

Для VK TURN укажите полный путь к JSON-файлу со своими данными приложения VK в переменной среды Windows `TNDTUN_VK_APP_CONFIG`, затем перезапустите TnDtun. Файл содержит массив объектов с полями `clientId` и `clientSecret`. Храните его отдельно от папки программы. Когда VK запрашивает CAPTCHA, нажмите «Проверить VK» и пройдите проверку вручную в браузере.

Время под «Обновить» показывает последнее успешное обновление. В списке подписок время указано отдельно для каждой записи. Когда панель включила автообновление, оно работает и при сворачивании приложения в трей.

В настройках можно задать, когда возвращать сплит-туннель: через 5, 15, 30, 60 минут или при отключении. «Всё в туннель» действует на текущий сеанс VK TURN либо Amnezia с включённым сплит-туннелем. Локальная сеть и соединения для работы самого VPN остаются доступны по физическим маршрутам.

При восстановлении Amnezia приложение может показать «Жду сеть» или «Ожидание восстановления». В режиме ожидания системный туннель освобождён. Чтобы прекратить восстановление, нажмите «Отключить». Крестик сворачивает приложение, команда «Выход» в трее отключает VPN и завершает программу.

Резервная копия профилей может содержать секреты для подключения. Для передачи программы используйте её ZIP, а для нового пользователя выпустите отдельную подписку.
