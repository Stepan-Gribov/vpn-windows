# TnDtun для Windows

VPN-клиент для Windows x64. Окно написано на C# и Windows Forms, сетевой процесс на Go. Режимы подключения: Amnezia, VK TURN и DNS/DNSTT. Клиент использует Wintun для системного туннеля.

Готовый ZIP для Windows x64 и его контрольная сумма доступны без входа в GitHub начиная с preview.5. [Раздел Releases](https://github.com/Stepan-Gribov/vpn-windows/releases)

В preview.4 переключатель «Всё в туннель» работает для VK TURN и Amnezia с включённым сплит-туннелем. Списки остаются сохранёнными, возврат происходит по таймеру либо при отключении. При смене маршрутизации Windows пересоздаёт системный адаптер, поэтому текущие потоки могут кратко прерваться.

Восстановление Amnezia выполняет сетевой процесс. При двух неудачных проверках стабильного пути он сначала пробует обновить сокеты. При отказе или сбое доставки пакетов освобождает маршруты и DNS своего адаптера, проверяет новый транспорт без захвата трафика и после этого восстанавливает захват. В ожидании используется обычный интернет. Отключение, потеря доступа и смена выбранного профиля останавливают восстановление старой сессии.

Клиент хранит дату последнего успешного обновления отдельно для каждой подписки. Автообновление включается только проверенным подписанным пакетом. Когда поле политики отсутствует, действует ручное обновление.
