# TnDtun для Windows

VPN-клиент на C# и Windows Forms для Windows 10/11. Интерфейс работает с
профилями подключения, импортом по QR и из файла, настройками DNS и списками
раздельной маршрутизации. Состояние подключения доступно из окна и трея.

- [app/TnDtun.cs](app/TnDtun.cs) — окна приложения, редактор профилей,
  настройки и связь с сетевым процессом через JSON RPC.
- [app/app.manifest](app/app.manifest) — манифест Windows-приложения.

В репозитории приведены выбранные исходники клиентского интерфейса для
портфолио. Для полноценной сборки требуется соответствующий сетевой процесс
на Go и драйвер Wintun.
